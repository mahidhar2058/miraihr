# MiraiHR

MiraiHR is planned as an independent, white-label, multi-tenant HRMS SaaS built by integrating mature Frappe applications. Phase P0 establishes requirements and architecture; it does not implement product features or deploy infrastructure. MiraiTeams is outside this repository.

## Status

P0 has an unresolved release compatibility blocker: India Payroll v16 is evidenced, while a compatible v15 release was not confirmed. Do not create a production app lock until compatibility gates pass. See [compatibility](docs/06-version-compatibility.md), [upstream inventory](docs/research/upstream-repository-inventory.md), and [P0 assessment](docs/planning/acceptance-gates.md).
