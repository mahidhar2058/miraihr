# MVP scope

Include branded HRMS core, employee lifecycle, attendance/leave, validated India payroll, local and selected corporate SSO, helpdesk, existing project/task/timesheet workflows, learning if version-compatible, per-customer isolation, lightweight admin registry, monthly active employee reports, manual invoicing, and PWA mobile.

Exclude payment gateways, wallets, automated invoices, custom ERP, NBFC lending integrations, native mobile apps, and unsupported upstream forks. Payroll accuracy and app compatibility are hard entry gates.
