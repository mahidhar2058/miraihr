# Acceptance gates

1. **P0 exit:** all requested docs present/nonempty, requirement IDs unique, links valid, source evidence dated, blockers visible. Current status: compatibility/license blockers remain.
2. **P1 compatibility:** exact immutable app revisions install and migrate together in a disposable environment; India payroll fixtures independently reviewed.
3. **Security:** automated tenant-isolation and authorization tests; threat review; secrets and dependency scans; no critical unresolved findings.
4. **Operational:** image provenance, staging rollout/rollback, encrypted backup and successful restore drill, alerts and runbooks.
5. **Pilot:** role-based browser acceptance, usage reconciliation, data protection review, support process and customer signoff.
